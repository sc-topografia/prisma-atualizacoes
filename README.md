# Prisma
Canal oficial de downloads e atualizações do Prisma, ferramentas de topografia da SC Topografia.
## Downloads
Os instaladores e as informações de cada versão serão disponibilizados em [Releases](https://github.com/sc-topografia/prisma-atualizacoes/releases).
O primeiro instalador está em preparação. Ainda não há uma versão publicada neste canal.
## Sobre este repositório
Este espaço é destinado aos arquivos de distribuição do aplicativo Windows. O código-fonte do programa permanece privado.
No aplicativo instalado, a opção **Sobre e atualizações** permitirá verificar novas versões, baixar a atualização em segundo plano e instalar em um momento seguro.
